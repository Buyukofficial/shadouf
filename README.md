## 🚀 Local Development

To run locally:
```bash
# Clone the repository
git clone https://github.com/Buyukofficial/shadouf.git
cd shadouf

# Run local web server (Python)
python -m http.server 5500
```
Open [http://localhost:5500](http://localhost:5500) in your browser.
